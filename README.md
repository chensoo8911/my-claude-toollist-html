## 這是什麼

由本機的 `toollist` skill 自動掃描產生並推送，每次執行整頁覆蓋＝內容永遠是最新狀態。頁面掛 `noindex`，不進搜尋引擎索引。

## 安全說明

- 只含工具的「名稱・用途・觸發詞」；claude.ai connector 的連線狀態一律遮蔽不顯示。
- 不含任何密鑰、token、API 串接資訊、本機路徑或個資。
- 產生器程式不在本 repo（在本機 skill 資料夾），這裡只有產出物。

### 本機路徑是怎麼擋掉的

工具的用途說明是直接從本機 skill 設定檔抄過來的，那些說明裡可能寫到檔案放在哪。產生器用三道防線處理：

1. **自動遮蔽**：組頁面前，所有 `/Users/...` 與 `~/...` 形式的路徑一律換成 `〔本機路徑〕`。
2. **黑名單比對**：再比對一份本機的敏感字清單（該清單刻意不放進任何 repo）。這一層是為了擋「沒有固定形狀、光靠樣式比對抓不到」的東西，例如個人資料夾名稱。
3. **寫檔前攔截**：只要前兩層任一命中，**整個程序中止**，不產生檔案也不推送——寧可同步失敗讓人來看，也不靜悄悄發佈出去。中止訊息只說命中第幾條規則，不會把命中的內容印出來。

> 2026-07-27 補上。在此之前只靠人工白名單，曾有一筆本機路徑漏到線上（已修正）。第 2 道防線是同日發版安檢覆查後才補的——只做樣式比對會漏掉沒有路徑形狀的私人名稱。
